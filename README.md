## 🛡️ PayGuard

**Agentic Payment Security & Orchestration Runtime for Razorpay**

PayGuard is a security runtime that allows AI agents to interact with payment infrastructure while keeping payment execution deterministic and auditable.

It separates AI decision-making from transaction enforcement through policy checks, risk analysis, approvals, and execution controls.

**Documentation:** https://payguard.sumeet.app
